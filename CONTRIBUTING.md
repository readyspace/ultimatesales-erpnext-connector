# Contributing

This repository is at internal-pilot alpha maturity. Open a focused issue/design discussion before widening business scope. Do not submit customer data or credentials. Use synthetic examples, explain the problem, add tests, and identify the exact Frappe/ERPNext/API contract involved.

Changes require the offline suite, code review, and relevant installed-site tests. Preserve the security and ownership invariants in AGENTS.md. AI-assisted code must be understood, reviewed and tested by its human maintainer; do not represent unexecuted tests as passing.

Public support/security channels and contributor governance must be set before public launch. This source bundle does not establish an official relationship with Frappe or HighLevel.
